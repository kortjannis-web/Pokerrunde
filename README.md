# Pokerrunde

Texas Hold'em gegen Bots und Blackjack gegen den Dealer, jeweils auch mit Freunden online, dazu Slots und Roulette.
Im Hauptmenü zur Seite wischen, um zwischen den Spielen zu wechseln (Pop the Lock · Slots · Poker · Blackjack · Roulette).
Beim Roulette spielt man allein, Freunde können aber jederzeit über die Freundesliste dazukommen.

Spielbar unter https://kortjannis-web.github.io/Pokerrunde/
