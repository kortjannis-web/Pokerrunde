# Pokerrunde

Texas Hold'em gegen Bots und Blackjack gegen den Dealer, jeweils auch mit Freunden online, dazu Slots, Roulette und Crash.
Im Hauptmenü zur Seite wischen, um zwischen den Spielen zu wechseln (Pop the Lock · Slots · Poker · Blackjack · Roulette · Crash).
Beim Roulette und bei Crash spielt man allein (bei Crash mit ein paar Bots), Freunde können aber jederzeit über die Freundesliste dazukommen.
Bei Crash steigt eine Rakete mit immer schneller wachsendem Multiplikator – rechtzeitig auszahlen, bevor sie abstürzt.

Spielbar unter https://kortjannis-web.github.io/Pokerrunde/
